# Selected native example

[Native notes](native-notes/README.md) is the current reference: a plain Cloudflare Worker with app-owned authentication, D1 and private R2 attachments. It uses no Userland runtime SDK.

Use the current catalog.json and https://docs.userland.fun/native-guide.md. The example does not promise a paid tier, live demo address, password recovery, email delivery or every Cloudflare feature. Discover available Account capabilities and test the app's required flows.

Other source folders are retained only as unadvertised historical references until the legacy backend removal is complete. They are excluded from the selected catalog and are not native quickstarts.
